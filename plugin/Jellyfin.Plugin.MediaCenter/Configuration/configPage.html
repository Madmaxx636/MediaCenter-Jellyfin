Media Center

Settings, notices and branding for the Media Center app on Android TV. Devices pick up changes the next time they start the app or go back to the start menu.

Everyone's settings apply to every device; a user's own settings go on top of them.

The list of settings arrives when a device with Media Center 0.9.8 or later connects to this server. Open the app once, then come back here.

SetSettingValueLock
"Set" pushes the value to devices (they can still change it); "Lock" also stops them changing it.
